# 🕷️ Homem-Aranha — Projeto Web

Projeto desenvolvido durante meus estudos em **Análise e Desenvolvimento de Sistemas (ADS)**, com foco na criação de páginas web utilizando **HTML e CSS**.

## 📖 Sobre o projeto

Este projeto apresenta uma página temática sobre o **Homem-Aranha**, explorando sua história, diferentes versões do personagem e o universo ao seu redor.

A proposta foi colocar em prática conceitos de desenvolvimento web, estruturação semântica, estilização e organização de arquivos.

## 📄 Páginas

O projeto é dividido em três páginas:

- 🕷️ **Homem-Aranha** — apresentação do personagem e sua história.
- 🦹 **Vilões** — informações sobre alguns dos principais vilões.
- 🌌 **Multiverso** — exploração de diferentes versões e universos do Homem-Aranha.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🎯 Objetivo

Praticar os fundamentos de desenvolvimento web e desenvolver um projeto utilizando HTML e CSS, aplicando conceitos aprendidos durante minha formação em ADS.

## 📚 Aprendizados

Durante o desenvolvimento, pratiquei:

- Estruturação de páginas com HTML5
- HTML semântico
- Organização de conteúdo
- Estilização com CSS
- Uso de imagens
- Links e navegação entre páginas
- Organização de arquivos e pastas
- Estruturação de um projeto para publicação no GitHub

## 🚀 Próximos passos

Pretendo continuar evoluindo o projeto e futuramente adicionar recursos utilizando **JavaScript**, tornando a página mais interativa.
